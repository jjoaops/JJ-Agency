# JJ Agency

Site institucional da JJ Agency, empresa de produtos digitais. Tema noturno com acentos neon.

- `index.html`: site completo em um único arquivo (HTML, CSS e JavaScript).
- Não precisa de build nem de instalação.

## Publicar no Vercel
1. Envie esta pasta para um repositório no GitHub.
2. No Vercel, clique em **Add New > Project** e importe o repositório.
3. Em **Framework Preset**, deixe **Other**. Não preencha build command nem output directory.
4. Clique em **Deploy**.

Antes de publicar, troque o e-mail `contato@jjagency.com` no final do `index.html`.
